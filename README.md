## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/balajidharma/learn-python.git
   cd learn-python
   ```

2. **Install Jupyter Notebook**
   ```bash
   pip install jupyter
   ```

3. **Launch Jupyter**
   ```bash
   jupyter notebook
   ```

4. **Start learning** — open any notebook from the table above and follow along.
